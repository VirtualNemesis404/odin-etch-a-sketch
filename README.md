# Etch a Sketch

The project is a browser version of sketchpad and Etch-a-Sketch.

## Overview

Etch a Sketch is a simple drawing application that lets users create sketches directly in their browser. This project helped me practice the fundamentals of web development, particularly DOM manipulation and JavaScript event handling.

## Technologies Used

- HTML5
- CSS
- JavaScript

## Getting Started

### Prerequisites
- A modern web browser
- Git installed on your system

### Installation

- Clone the repository : 

    ```bash
    git clone https://github.com/VirtualNemesis404/odin-etch-a-sketch.git
    ```
- Navigate to the directory :

    ```bash
    cd odin-etch-a-sketch
    ```
- Open the index.html in browser.

## Concepts Learned

- HTML structure and semantics
- CSS styling and layout
- DOM manipulation using JavaScript
- JavaScript event handling
- Dynamic creation and interaction of page elements
